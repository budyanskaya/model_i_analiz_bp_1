# Моделирование и анализ бизнес-процессов
## Задача 1. 
*Сценарий:* «Обработка возврата товара в интернет-магазине»
*Описание:* Клиент подаёт заявку на возврат → оператор проверяет условия → приём товара на складе → проверка состояния → решение о возврате средств или отказе → уведомление клиента.
Задание. Моделирование в Draw.io (45 мин)
1. Создайте диаграмму с двумя пулами: «Клиент» и «Компания».
2. В пуле «Компания» выделите дорожки: «Оператор службы поддержки», «Склад», «Бухгалтерия».
3. Отразите полный цикл возврата с использованием:
-  	Начального события «Заявка на возврат получена»
-  	Шлюза «Условия возврата соблюдены?» (исключающий)
-  	Параллельного шлюза для одновременной проверки состояния товара и документов
-  	Конечных событий «Возврат средств выполнен» и «Отказ в возврате»
4. Добавьте объекты данных: «Акт приёма», «Заявление на возврат».
5. Сохраните файл в формате draw.io и экспортируйте как PDF.
